## Sobre o Projeto

Landing page temática inspirada no universo do **Homem-Aranha**, desenvolvida como projeto de estudo com foco em **design moderno, responsividade e experiência do usuário**.

O projeto simula uma campanha promocional visual completa — com animações, layout dinâmico e identidade visual imersiva baseada no universo Marvel.

---

## Funcionalidades

- 📱 **Layout 100% responsivo** — adaptado para desktop, tablet e mobile
- 🎨 **Design temático imersivo** — paleta, tipografia e elementos do universo Spider-Man
- 🌀 **Animações e transições suaves** — CSS animations + JavaScript interativo
- ⚡ **Performance otimizada** — estrutura limpa e assets organizados
- 🎬 **Vídeo de background** — elemento cinematográfico na hero section

## Estrutura do Projeto
```
spiderman-landing-page/
├── css/           # Estilos compilados
├── fonts/         # Tipografia customizada
├── images/        # Assets visuais
├── js/            # Scripts de interatividade
├── svg/           # Ícones e elementos vetoriais
├── video/         # Vídeo de background
└── index.html     # Página principal
```

## Como Executar
```bash
# Clone o repositório
git clone https://github.com/Oberon-23/spiderman-landing-page.git

# Acesse a pasta
cd spiderman-landing-page

# Abra no navegador
start index.html
# ou use Live Server no VSCode para hot reload
```
